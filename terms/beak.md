## Definition

The hardware/software infrastructure layer that feeds the whole system — sensors, interfaces, compute, storage, networking, UPS, monitoring. Also used adjectivally: a tool is "Beak" if MCP-exposed, "non-Beak" if it's a plain homelab utility.
