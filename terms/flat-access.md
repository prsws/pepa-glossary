## Definition

The burden of knowing where a thing is belongs to Pepa, never to the user. A memory must be reachable from any term the user actually holds — object, room, person, day, occasion, reason — and every path resolves to the same entry. No memory has a single canonical access path. Extends to presentation: flatness is the default, nesting requires justification.
