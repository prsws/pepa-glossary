## Definition

The name used for the Home Assistant voice and chat agent in the May 2026 specification. It was refactored into the Pepa Sensory Arm at version 3. The older repository name still carries the old spelling.

## History

- 2026-05-21: Specified as the Pepa Arm Home Agent.
- 2026-09-04: Glossary v0.1 noted that both PAHA and PSA were in live use for the same arm, and asked for a ruling.
- Version 3 of the Sensory Arm (date to confirm): refactored into the Pepa Sensory Arm; PAHA became a superseded name.
