## Definition

Checks Pepa's health without using a language model, because a model watching a model has no one watching it. Its body is an Orange Pi Zero 2W, which already monitors both battery backups and the inference hosts. The arm's own logic is not built yet.

## History

- 2026-09-04: Glossary v0.1 listed it as the Self-Monitor Arm.
- 2026-09-21: Named the Pepa Self Monitoring Arm (PSMA), replacing the abbreviation SMA.
- 2026-10-03: The Orange Pi went live monitoring both battery backups; described as a hardware appendage, with the arm's logic still to come.
