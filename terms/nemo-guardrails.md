## Definition

The safety-rail framework (Colang policy) validating inputs, outputs, and tool calls. In PAHA it hooks at the tool-validation layer between LLM proposal and HA dispatch, and does not run on preprocessor hits (pre-audited). Placement across PSA is still lane P7, unbuilt.
