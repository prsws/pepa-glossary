## Definition

Cited in the same breath as HarnessX and NOOA as evidence that harness quality is the only lever at small model size. Elsewhere described as a broad local-agent framework with a Tools & Memory layer, semantic indexing over personal documents, and MCP — "more of a broad framework" than a memory system. **The two usages don't obviously line up, and no doc defines the harness-thesis sense.** Needs a source and a decision on which sense is canonical.
