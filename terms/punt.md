## Definition

The local LLM delegating a query to the External LLM via the `query_external_llm` tool. Purely model-decided; the only controls are the tool description text and the system prompt's routing rule. Today's escalation seam. **Update 2026-10-31 (v0.2):** still the live seam. Under the Option C proposal (proposed 19 Sep 2026) it becomes the briefed escalation envelope to the Head, and "punted" also names one of the Head's three exits.
