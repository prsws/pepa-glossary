# Open items

Questions about the glossary itself that are not settled. Edit this file by hand. When one is settled, move it to the bottom under "Settled" with its date; do not delete it.

## Open

1. **HarnessX and OPENJARVIS have no defining source.** Both are used in the harness-quality argument. Each needs a citation, or the claim should be attributed to NOOA (NVIDIA's object-oriented agent harness) and Self-Harness alone. A web search on 30 Oct 2026 found a HarnessX paper at arXiv 2606.14249, not yet confirmed as the work Pepa cites. Some project notes attach arXiv 2606.09498 to HarnessX, the number this glossary gives to Self-Harness; one of the two is wrong. See [HarnessX](terms/harnessx.md), [OPENJARVIS](terms/openjarvis.md), [Self-Harness](terms/self-harness.md).
2. **The arm roster differs by document.** An early founding document lists six arms, a later roadmap lists eleven (including Thinking, Storage, Coding, Maintenance), and other documents add a User Health Arm and an Inference Arm. The names have since grown: Pepa Human Sentinel Arm (PHSA), Pepa Self Monitoring Arm (PSMA), the Pepa Auditor Arm and a Conversation Arm. The older repository `prsws/pepa-user-health-arm` overlaps the Sensory Arm's human scope. A single canonical roster needs José's ruling.
3. **Is the Head deterministic or does it keep a model in the loop?** Narrowed by the Option C proposal, not decided. The glossary cannot define "Head" precisely until it is. See [Head](terms/head.md), [Option C](terms/option-c.md).
4. **Where is the Head hosted?** mm2010 was withdrawn on 2 Oct 2026, but some design documents still assume it.
5. **Repository pass not yet run.** The terms come from earlier private drafts, ai4aging.org and project chats only.
6. **José's error list from the 2026-09-04 skim** is still pending as far as the last pass could tell, so the v0.1 entries have not had those corrections applied.
7. **Acronym handling.** José has a separate idea for acronyms, to be shared later.

## Settled

- **PSA versus PAHA** (settled 31 Oct 2026): PAHA is a superseded name, replaced by the Pepa Sensory Arm at version 3 of the Sensory Arm. See [PAHA](terms/paha.md).
